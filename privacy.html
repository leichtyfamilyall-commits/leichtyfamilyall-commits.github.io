Privacy Policy — Leichty Family Assistant

Leichty Family Assistant is a private application used by a single household. It is not offered to the public and has no users outside that household.

What it accesses

With each household member's explicit consent, the application reads and writes events on that person's own Google Calendar, and on a shared family calendar owned by the household. It requests only the calendar.readonly and calendar.events scopes, plus basic profile and email address in order to identify which household member granted access.

How data is used

Calendar data is used solely to answer that household member's own questions and to create or update events at their request. It is processed on a private server operated by the household.

What is not done
